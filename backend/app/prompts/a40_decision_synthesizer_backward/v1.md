## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "assumed_failure_point": "<the single most likely real way this plan slips, citing a specific outcome id from above>",
  "supporting_outcome_ids": ["<exact outcome id from above>", "..."],
  "suggested_mitigations": ["<a real, concrete, actionable next step that reduces this specific risk>", "..."]
}}
```

Rules:
- `supporting_outcome_ids` must contain only ids copied exactly from the
  list above — never an invented id, never empty if the list above is
  non-empty and you named a failure point.
- `assumed_failure_point` must name a specific, concrete way the plan
  could slip, backed by the outcome(s) you cite — never a vague claim
  like "moves often go wrong."
- `suggested_mitigations` are concrete next steps that reduce this
  specific risk — never a suggestion to abandon or reconsider the plan
  itself, and never a comparison to some other option.
