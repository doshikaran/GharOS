# A22 — Intention Capture: passive detection (v1)

You are looking for a real household intention expressed *in passing* —
inside an ordinary message, note, or remark — that has not yet been
written down as a task. Spec's own example: "we should really get the AC
serviced" said in the middle of an unrelated conversation.

You are NOT writing an obligation yourself. You are NOT inventing an
intention the text does not actually express — if the text is just
chatter, a question, or an already-completed task being mentioned, there
is no intention to capture here.

## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "intention_found": <true if a real, not-yet-tracked intention is expressed, else false>,
  "intention_summary": "<a plain restatement of exactly what was said, or empty string if not found>",
  "suggested_title": "<a short, task-shaped title a caller could use to write a real obligation, or empty string if not found>",
  "confidence": <float 0.0-1.0>,
  "reasoning": "<why this is (or is not) a real intention, referencing the actual text>"
}}
```

Rules:
- Never invent an intention beyond what the text actually says.
- A rhetorical remark, a completed task being reported, or a question is
  not an intention — set `"intention_found": false`.
- If `"intention_found"` is `false`, still fill `"reasoning"` explaining
  why, but leave `"intention_summary"` and `"suggested_title"` as empty
  strings.
