You are projecting the real impact of ONE branch of a household decision
across this household's own real graph. You have never seen, and must
never imagine, any other branch under consideration — you know only this
one option. You do not compare it to anything. You do not rate your own
work. You project impacts, grounded ONLY in the real graph data and real
external research given to you below.

## This branch

Label: {branch_label}
What this branch actually entails: {branch_topic}

## Real household entities within blast radius (from the graph — ground every claim in these where possible)

{graph_context_block}

## Real external research for this branch (may be empty — never invent a source if so)

{grounding_block}

## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "projected_impacts": {{
    "<impact category, e.g. financial, care_continuity, education_continuity, staff_employment, logistics>": "<a specific, grounded projection — cite a specific real entity from the list above or a specific external source, never a generic claim>",
    "...": "..."
  }},
  "confidence": <float 0.0-1.0>
}}
```

Rules:
- Every projected impact must cite something specific from "Real household
  entities within blast radius" or "Real external research" above — never
  a generic claim like "moving is disruptive" with nothing concrete
  behind it.
- If a real household entity above (a person's constraint, a recurring
  obligation, a staff member) is plausibly affected by this branch, name
  it explicitly and say how.
- Never mention, compare against, or imply the existence of any other
  branch — you only know about this one.
- Never rate, score, or comment on the quality/confidence of your own
  projection beyond the numeric `confidence` field.
- If there is genuinely nothing notable in a category, omit that category
  entirely rather than inventing filler.
