## Your task

For every real, meaningful span of the transcript (words, numbers, dates,
kinship references — not every single individual filler word), produce
one normalised span:

- **`kind: "plain"`** — ordinary words. `normalized_text` collapses
  transliteration variance to one canonical spelling (e.g. "nahi",
  "nahin", "nhi" all normalise to "nahi"). If nothing needs normalising,
  `normalized_text` equals `original_text` exactly.
- **`kind: "amount"`** — any spoken money amount. Resolve lakh/crore
  conventions and spoken-out numbers ("saade teen hazaar" = 3500,
  "do lakh" = 200000) to a real numeric `amount_value` (a plain number,
  no currency symbol, no digit grouping — that formatting is applied by
  code afterward). If the amount is **genuinely ambiguous** — spoken as
  an approximate range ("teen-chaar hazaar", "three-four thousand") or
  otherwise not resolvable to one figure with real confidence — set
  `"ambiguous": true` and do NOT include `amount_value` at all. **Never
  guess, round, split the difference, or pick the first candidate** —
  an ambiguous amount that feeds a payment is a real-money bug, not a
  minor imprecision.
- **`kind: "date"`** — any date/time reference. Resolve a relative
  expression ("kal", "Friday", "agle hafte") to an absolute date using
  today's date above, and write `normalized_text` as that absolute
  date/time in a clear, unambiguous form.
- **`kind: "kinship"`** — a kinship term used to refer to a person
  ("Amma", "Baba", "Kaku", "Didi", "Mausi", "Kaka", "Mama", etc.).
  `normalized_text` corrects transliteration variance in the term itself
  (e.g. consistent romanisation) but you must **never** translate it into
  English or another language, and you must **never** guess which real
  person it refers to — that is a separate downstream step, not your job.

## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "spans": [
    {{
      "original_text": "<the exact original substring>",
      "normalized_text": "<the canonical form>",
      "kind": "<plain|amount|date|kinship>",
      "language": "<en|hi|mr|es>",
      "start_char": <integer offset into the transcript>,
      "end_char": <integer offset, exclusive>,
      "amount_value": <number — ONLY present when kind is "amount" and NOT ambiguous>,
      "ambiguous": <true or false — ONLY meaningful when kind is "amount">
    }}
  ],
  "confidence": <float 0.0-1.0 — overall confidence in this normalisation pass>
}}
```

Rules:
- `original_text` must always be present and must always be the real,
  unmodified original substring — never omit it, never blank it, even
  when `normalized_text` is identical to it.
- Only include `amount_value` when `kind` is `"amount"` and `"ambiguous"`
  is `false`.
