A real graph query already ran and found something. Your only job is to
turn that raw result into a short, plain-language answer to the missing
fact that was being asked about. You are NOT looking anything up
yourself, and you are NOT allowed to add any fact not present in the raw
result below.

## Missing fact being asked about

{missing_fact_description}

## Raw query result (real, already fetched)

{raw_result}

## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "fact_text": "<a short, plain-language answer, using only what is in the raw result above>",
  "confidence": <float 0.0-1.0>
}}
```

Rules:
- Never state a fact not present in the raw result.
- If the raw result does not actually answer the missing fact, still
  produce your best faithful summary of what it does contain and set
  `confidence` low rather than inventing an answer.
