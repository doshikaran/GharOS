# A64 — Language & Script Identifier (v1)

You are tagging one real household voice turn with per-**span** language
labels. This is a household in India that speaks a real mix of English,
Hindi, and Marathi within single sentences — this is normal, expected
household speech, not an error in the transcript.

## The turn's real transcript (verbatim — never rewrite, translate, or
"clean up" this text; you are tagging it exactly as given)

{raw_text}

## Your task

Split the transcript into contiguous spans, and tag each span with
exactly one language: `"en"` (English), `"hi"` (Hindi), `"mr"` (Marathi),
or `"es"` (Spanish). A span may be as short as one word or as long as a
clause — split wherever the language genuinely changes, including
mid-sentence (English nouns inside Hindi/Marathi grammar are extremely
common — e.g. "field trip" inside an otherwise-Hindi sentence is an
English span inside a Hindi sentence, not evidence the whole sentence is
English).

## Hindi vs Marathi — disambiguate by lexicon and grammar, NEVER by script

Hindi and Marathi are both commonly romanised (Latin script) in real
household speech, and even in Devanagari they share the same script — so
script tells you nothing about which of the two a span is. Use these real
lexical/grammatical markers instead:

- **Copula (the verb "to be"):** Hindi uses "hai"/"hain"/"ho"/"tha"/"thi".
  Marathi uses "aahe"/"ahe"/"aahet"/"hota"/"hoti". "Society maintenance
  cha payment kela ka" is Marathi because of "kela" (Marathi past-tense
  verb form) and "ka" as a question particle in this construction, not
  because of anything else.
- **Possessive suffix:** Hindi uses "ka"/"ki"/"ke" (e.g. "Aarav ka
  school"). Marathi uses "cha"/"chi"/"che" (e.g. "Aarav cha school").
- **Negation:** Hindi "nahi"/"nahin". Marathi also uses "nahi" — this
  word alone is **not** a reliable disambiguator; look at what surrounds
  it.
- **Common Marathi-specific words:** "kay" (what), "zala"/"zali" (happened),
  "tyacha"/"tichi" (his/her), "ahe"/"nahi ahe".
- **Common Hindi-specific words:** "kya" (what), "hua"/"hui" (happened),
  "uska"/"uski" (his/her).

**Some short utterances are genuinely, irreducibly ambiguous** — e.g.
"Aaj nahi" ("not today") uses identical vocabulary in both languages with
no grammatical marker present at all. When you cannot find a real
lexical or grammatical marker that decides it, say so honestly: report a
low `confidence` (below 0.6) and populate `ambiguous_between` with every
language you genuinely cannot rule out. **Never pick one arbitrarily and
report high confidence** — an honest "I cannot tell" is far more useful
downstream than a confident guess.

## Output

Respond with ONLY a single JSON object, no markdown fences, no
commentary, matching exactly this shape:

```json
{{
  "spans": [
    {{
      "text": "<the exact substring of the transcript this span covers>",
      "start_char": <integer offset into the transcript, 0-based>,
      "end_char": <integer offset, exclusive>,
      "language": "<en|hi|mr|es>",
      "confidence": <float 0.0-1.0>,
      "ambiguous_between": ["<language code>", "..."]
    }}
  ],
  "overall_confidence": <float 0.0-1.0 — the turn's overall tagging confidence>
}}
```

Rules:
- Spans must be contiguous and cover the entire transcript, in order,
  with no gaps and no overlaps.
- `ambiguous_between` is an empty array `[]` for every confidently-tagged
  span — only populate it when you genuinely cannot lexically/
  grammatically decide between two or more languages for that exact
  span.
- Never translate, paraphrase, or correct spelling inside `"text"` — it
  must be an exact substring of the transcript above.
